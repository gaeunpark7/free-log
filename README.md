# 프리로그 - 프리랜서 작업 관리 & 수익 계산

<p align="center">
<img src="img/banner_image.png" alt="배너 이미지" width="95%" >
</p>

> **"프로젝트 관리부터 작업시간 기록, 수익 계산까지 한 번에 관리하는 프리랜서 작업 관리 앱"**<br>
> 프로젝트 관리, 작업시간 기록, 수익 및 지출 관리, 캘린더, 통계를 하나의 앱에서 제공하여 프리랜서의 업무 관리를 지원합니다.

<br>
<br>


## ✨ Introduction

<p align="center">
<img src="img/intro_image.png" alt="소개 이미지" width="1500" height="400">
</p>

| 기능                 | 설명                                               |
| -------------------- | -------------------------------------------------- |
| `프로젝트 CRUD`        | 프로젝트 생성, 수정, 삭제 및 관리                  |
| `할 일, 작업시간, 수익, 지출 CRUD`     | 프로젝트별 작업 내역과 수익, 지출 관리         |
| `캘린더 및 통계`        | 월별 작업 기록과 수익, 지출 통계 확인           |
| `즉석 금액 산출 계산기`      | 작업 금액을 빠르게 계산                          |
| `프로젝트 마감 알림`    | 프로젝트 마감일 푸시 알림 제공                    |
| `다국어 지원` | 한국어, 영어 지원 |
<br>
<br>
